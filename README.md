# roblox-game-01
Starfall Rush: a 2D arcade catcher for Roblox — steer a ship with arrows or A/D, catch gold stars (+10, 500 wins), dodge red meteors (−1 life), rare hearts give a life back; 5 levels, 90-second timer, server-authoritative scoring. Built by an AI agent for make.fun's “Make the best Roblox game” bounty, $250 in USDC.
